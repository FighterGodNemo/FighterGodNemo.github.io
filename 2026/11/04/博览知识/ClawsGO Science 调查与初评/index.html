ClawsGO Science 调查与初评：一条邀请链接背后的科研 Agent

发表于2026-11-04|更新于2026-11-04|博览知识
|总字数:1.3k|阅读时长:4分钟

起因：收到一条带邀请码的链接（clawsgo.science，链接含邀请码，利益相关声明见文末）。本文是基于本机实测 + 公开资料检索的调查笔记，非推广文——所有判断都标注了证据等级。

它是什么

ClawsGO Science（运营主体：BitMiracle Technology Limited）是一个面向科研/数模场景的 AI Agent 产品：

  • 你交任务，它编排多家模型去查文献、跑代码、操作浏览器、写 LaTeX、出图表，交付成套文件；
  • 任务可跑在云端主机，也可通过桌面端连到你自己的电脑/实验室 GPU（SSH 接入 + 本地 daemon，思路类似 Devin 的 BYOM）；
  • 官网宣称场景：文献综述、meta 分析、论文写作、图表复现包（图+代码+环境+版本史）。

产品形态三层：Web 应用（app.clawsgo.science）+ 桌面端（Win EXE / Mac DMG）+ 云主机运行时。手机号短信登录，18+。

口碑检索（2026-11-04）

不是空壳：知乎有创始人专访（00 后辍学创业者）、什么值得买报道其”AI 破解化学动力学猜想”的 23 页论文宣传、CSDN 有多篇数学建模实战评测、B 站有数模论文生成演示视频，第三方目录（PoweredByAI）收录，甚至有开源项目自称 UI”参考 ClawsGO 与 Codex”。

社区评测的共识口径值得记录：它不是”自动解题机/论文 fabriacter”，卖点是流程效率——TOPSIS 到成稿的流水线、数据清洗/画图/公式/排版自动化，”辅助而非替代思考”。

两条要打折扣的：①”解决 50 年猜想”是宣传性声明，未经同行评议，当营销看；②官网 demo 里文献 mockup 有明显摆拍痕迹。另外一条要反向澄清：官网列的 Claude Fable 5.1 / GPT 6 Astra 不是假模型名——它们是当前 Devin/DSH 生态真实在售的模型（CLIProxyAPI 文档可查），第一眼觉得假是因为名字太”故事化”。

红旗与绿灯清单

绿灯：真实运营主体与媒体覆盖；条款质量罕见地规范；产品定位清晰（科研/数模流水线）；未被任何社区标记为诈骗。

红旗：安装包未签名还教人绕 SmartScreen（早期创业公司没钱买签名证书很常见，但对用户意味着零供应链保障）；定价不透明 + 邀请积分增长体系（本文链接就带邀请码）；服务 2026-11-08 才生效，零口碑沉淀期；”破解猜想”式营销话术。

对学生党/数模选手的价值判断

有真实匹配点：数模竞赛论文流水线（数据处理→模型→图表→LaTeX 排版）恰好是它主打场景，也是纯体力活密集、AI 增益最大的环节。如果你在备赛，值得用 Web 版试一次完整任务流。

不建议现在做的事：在实名主力机上装那个未签名 EXE。桌面端的增量价值是”agent 在本地文件系统跑任务”，但这完全可以等两件事发生再说：①口碑沉淀 1-2 个月；②它出签名版安装包。校内机器更不要绑 SSH——privacy 里写明它会存 SSH 服务器信息并代你在其上执行任务。

如果要试，最安全的路径

  1. 只用 Web 版（app.clawsgo.science），手机号注册，先跑一个公开数据的小任务（如”对某公开数据集做 TOPSIS 并出三张图”）；
  2. 看每次任务是否真的标明用了哪个模型、花了多少积分（条款承诺可见）；
  3. 评估产出质量后再决定是否充值/邀请；
  4. 桌面端与 SSH 绑定：等签名、等口碑、用非主力机。

结论

产品是真的，青春期的。 定位聪明（数模/科研流水线是刚需），法律文书合格，营销激进，供应链安全不达标。给它的评级：Web 版可试、桌面端缓装、宣传话术当广告看。一个月后值得回访看定价公开情况和社区口碑变化。
