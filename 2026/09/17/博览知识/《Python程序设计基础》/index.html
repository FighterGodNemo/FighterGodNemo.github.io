3.2 元组（tuple）

元组是有序、不可变的序列，俗称“不能修改的列表”。

3.2.1 决定元组的是逗号，不是括号（重点易错）

括号在 Python 里是表达式分组符，只有当逗号出现时，括号才变成“元组构造符”。

3.2.4 与列表的选择

列表 [] 元组 ()
可变性 可增删改 不可变
性能 稍慢 更快、内存占用更小
用途 动态数据集 固定结构、常量记录

判断原则：数据要变用列表，一组固定值用元组。

3.2.7 操作速查：不可变元组怎么”改”

一条总原则：元组锁的是每一层元素的引用，不锁元素内部。

需求 合法写法 禁忌
查第一个元素 t[0]；要保留结构用 t[:1] —
查值在第几位 t.index(值)，只返回首个，找不到报 ValueError —
查所有匹配位置 [i for i, v in enumerate(t) if v == 目标] —
删元素 本身做不到；用 t[:i] + t[i+1:] 重建，或 tuple(list(t)) 中转 del t[i]、t.remove(x)
改元组内列表的某个元素 t[i][j] = 新值 t[i] = [...]
整块换掉列表内容 t[i][:] = [新值] / clear()+append() 同上
删整个变量 del t（解除名字绑定，非删元素） —

三条判断法则：

  1. 看动的是哪一层：只改内层可变对象（list/set/dict），永远合法；换元组某个位置的引用，必然 TypeError。
  2. 要换整个元素：优先 t[i][:] = [...]（原地、同对象）；需要真正换绑定就用 t[:i] + (新值,) + t[i+1:]，别忘单元素尾逗号。
  3. 业务要频繁增删改 → 直接用列表；元组的价值是固定结构、更省内存、可作字典键。

记忆口诀：元组 = 有顺序 + 不可改 + 逗号决定；单元素那个逗号不是多余装饰，而是告诉解释器“我要元组”。
