科技日报 - 2026年8月10日 星期一

关注方向：AI Coding · 具身智能 | 精选 5 条

1. 宇树科技科创板申购：人形机器人第一股诞生，219 倍 PE 震撼市场

事件： 8 月 10 日，宇树科技（Unitree）正式启动科创板网上网下申购，发行价 150.80 元/股，对应市值约 610 亿元，发行市盈率高达 219 倍（行业均值仅 38.56 倍），募资总额约 61 亿元，较原计划超募近 19 亿元。社保基金、深度求索、中石油等获战略配售。公司 2025 年营收 16.99 亿元，人形机器人收入占比已过半，全球市占率约 32.4%，出货超 5500 台。90 后创始人王兴兴持股 33.36%，身价逼近 200 亿元。

关注原因： 这是具身智能赛道在公开资本市场的历史性定价事件。219 倍 PE 表明市场对人形机器人商业化前景给出了极端乐观的估值，远超传统制造业和一般科技公司。超募近 19 亿元意味着资本弹药充足，将加速人形机器人的量产与生态建设。宇树的上市也为整个具身智能赛道提供了估值锚点——优必选、乐聚、云深处、越疆等后续 IPO 都将以此为参照。

2. Meta 开源 Muse Glimmer：30B Agent 模型可在消费级 GPU 上运行

事件： Meta 于 8 月 10 日发布 Muse Glimmer，Apache 2.0 开源 300 亿参数多模态密集模型，专为本地 Agent 工具使用、编程和 LLM-as-Judge 优化。支持 131K 上下文、100+ 种语言，4bit 量化后压缩至 20GB 以下，可在单张 24GB/32GB 显存 GPU 上运行。在 RTX 5090 上通过推测解码实现 3.1 倍加速。扎克伯格同时发表了一篇 6500 字长文阐述开源 Agent 愿景。

关注原因： Muse Glimmer 的核心价值在于「Agent 本地化」——不需要云端 API 就能在个人电脑上运行完整的 AI Agent。这对 AI Coding 场景意义重大：开发者可以在本地完成代码生成、工具调用、代码审查等全流程，数据不出本机，延迟极低。30B 参数达到可用水平，意味着端侧 AI Coding 不再依赖闭源 API，开源 Agent 模型的竞争正式进入「消费级硬件可运行」阶段。

3. Docker 发布 AI Agent 沙箱 + Claude Code 默认启用 Auto Mode：Agent 自主编程进入「无人监督」时代

事件： Docker 于 8 月 10 日推出 Docker Sandboxes，为 AI 编程 Agent 提供隔离的 microVM 运行环境，支持 Claude Code、Gemini CLI、Copilot CLI、Codex、OpenCode 和 Kiro，具备文件系统和网络控制功能。同一天，Anthropic 宣布从 8 月 14 日起为 Pro/Max/Team 用户默认启用 Claude Code Auto Mode，用分类器替代人工审批。内部测试显示分类器捕获 89% 危险命令，而人工审核仅捕获 13.6%。启用 Auto Mode 的团队 PR 产出量增加约 25%。

关注原因： Docker + Claude Code 的组合拳标志着 AI 编程 Agent 从「需要人类盯着」到「独立自主运行」的关键转变。Docker 解决了安全隔离问题（沙箱内搞不坏宿主机），Claude 的 Auto Mode 解决了信任问题（机器审查比人更可靠）。两者结合意味着 Agent 可以在无人监督下完成代码编写、测试、提交的全流程——这在几周前还是不可想象的。25% 的 PR 产出增幅说明「无人监督 Agent 编程」已是真实的生产力提升，而非概念验证。

4. Agent Plugins 1.0 发布：六大巨头联手统一 AI 插件标准，Anthropic 缺席

事件： 8 月 6 日，OpenAI、Microsoft、Amazon、Cursor、Vercel 联合发布 Agent Plugins 1.0 开放规范，Google 作为核心维护者加入。该规范将 Agent Skills 和 MCP 服务打包为单一可移植目录（plugin.json + skills/ + mcp.json），一次打包即可跨客户端使用。值得注意的是，Anthropic（Claude）缺席了该联盟——尽管规范结构「撞脸」Claude 现有插件系统。

关注原因： 这是 AI 工具生态走向标准化的里程碑。开发者不需要为 Codex、Cursor、GitHub Copilot 各做一套插件适配，就像 USB-C 统一了充电接口。对 AI Coding 领域而言，统一插件标准意味着工具链的互操作性大幅提升，开发者生态可以更高效地协作。但 Anthropic 的缺席也暗示了 AI Coding 工具市场可能走向「阵营化」——以 OpenAI/微软为首的开放联盟 vs Claude 独立生态。

5. 中国占据全球 97% 人形机器人出货量，深圳已见「机器人交警」

事件： 彭博社援引 Smart Analytics Global 数据，2026 年上半年全球人形机器人出货量约 19,100 台（去年全年仅 5,100 台），中国制造商占据超过 97% 的份额。新华社同步发布深圳专题报道：人形机器人已在深圳餐厅送餐、邮局分拣包裹、福田区指挥交通、公园制作冰淇淋，具身智能已从实验室走进城市日常。

关注原因： 97% 的出货量占比说明中国在人形机器人的商业化量产上已形成压倒性优势。结合宇树上市的同日新闻，具身智能正经历「资本 + 量产 + 场景」三重加速。深圳的「机器人交警」和「机器人邮递员」则证明，具身智能的场景落地已不再是 Demo，而是正在被纳入城市基础设施。具身智能的「iPhone 时刻」可能比预期来得更快。
