DPI 鼠标硬件灵敏度，越高光标移动越快
Sens CS2 游戏内灵敏度滑块值

职业选手 eDPI 基准：中位数约 800-850，多数集中在 600-1000 区间。

四、位置与灵敏度规律

位置类型 典型 eDPI 范围 特征说明

IGL（指挥） 560-850 普遍偏低敏，追求稳定性
自由人（Lurker） 600-800 偏低敏，重视架枪与微调精度

五、关键配置建议

  1. eDPI 比单独看 DPI 或灵敏度更有意义 — 400 DPI × 2.0 = 800 eDPI 与 800 DPI × 1.0 = 800 eDPI 手感完全一致
  2. 大部分职业选手保持 Zoom Sensitivity = 1.0 — 不建议随意改动开镜灵敏度
  3. 原始输入（Raw Input）必须开启 — 所有职业选手标配
  4. 鼠标加速必须关闭 — Windows 指针速度保持 6/11
  5. 找灵敏度的方法：从 800 eDPI 出发，在死斗/瞄准训练中分别测试 ±10% 和 ±20%，选择分数最高的那个值，然后稳定使用至少 2-4 周
