二、大模型：GPT-5 登场，上海队崛起

2.1 OpenAI GPT-5（2025.08.07）

OpenAI 于 8 月 7 日正式发布 GPT-5，这是自 o 系列推理模型与聊天模型分流以来，首个统一旗舰模型。核心变化：

  • 统一路由架构：模型自行判断何时需要「思维链推理」、何时直接回答，用户无需手动在聊天模型和推理模型间切换。
  • 400K Token 上下文窗口，可一次读入海量文档。
  • 幻觉率大幅下降：相比 GPT-4o 减少约 45%；深度思考模式下相比 o3 减少约 80%。
  • 定价低廉：前沿能力搭配商品级价格，直接冲击所有靠卖 token 为生的中间层。

评价：GPT-5 的定价比基准测试分数更重要。它把「前沿模型」变成了「基础设施定价」。

2.2 OpenAI 开源：gpt-oss-120b / gpt-oss-20b

8 月 5 日，OpenAI 发布自 GPT-2（2019 年）以来的首批开源权重模型，采用 Apache 2.0 许可证：

模型 特点
gpt-oss-120b MoE 架构，4-bit MXFP4 量化；单张 80GB GPU 即可运行；推理能力接近 o4-mini
gpt-oss-20b 约 16GB 显存即可运行，适合边缘设备和笔记本电脑；质量接近 o3-mini

意义：这是 OpenAI 重返开源竞技场的标志性事件。此前最强开源推理模型来自 Meta、Mistral 和中国实验室，现在 OpenAI 以 Apache 2.0 许可加入战局，彻底重置了开源基准线。

关键趋势：纯语言模型能力接近触顶，多模态融合成为通向 AGI 的共识路径。上海队的崛起说明「坚持多模态路线 + 底层架构创新」是正确的战略选择。

2.4 DeepSeek-V3.1（2025.08.21）

DeepSeek 发布 V3.1 大语言模型，三大核心升级：

  • 混合推理架构：一个模型同时支持思考模式与非思考模式
  • 简单问题快速回答，复杂问题深度推理
  • 更强的智能体（Agent）能力

2.5 Anthropic Claude Opus 4.1

8 月 5 日发布，低调但重磅：

  • SWE-bench Verified 达 74.5%（当时 SOTA 编程分数）
  • 同价同上下文窗口（200K），纯模型能力提升
  • API 上直接替换字符串即可升级

三、AI 编程：开源模型全面对标闭源

3.1 Qwen3-Coder — 阿里开源编程旗舰（2025.07.23）

  • 千问系列首个 MoE 架构 代码模型：4800 亿总参数，350 亿激活参数
  • 原生 256K 上下文，可扩展至 1M Token
  • 在 Agentic Coding、浏览器操作、工具调用 三项评测中刷新开源 SOTA
  • 直接对标 Claude 4 Sonnet
  • 同步开源完整工具链：Qwen Code CLI、Claude Code 集成、VS Code 插件

3.2 Qwen3-Coder-Flash（2025.08.01）

轻量版：30B 总参数 / 3B 激活参数，专注 Agent 能力，适合本地部署和快速推理。

趋势洞察：编程模型的竞争已从「写代码」升级为「代理式编程」——模型不仅要生成代码，还要理解代码仓库、操作浏览器、调用工具、执行多步骤任务。Qwen3-Coder 的完整工具链开源，将大幅降低 AI 编程的门槛。

四、AI Agent & 多模态智能体

4.1 字节 M3-Agent：多模态记忆智能体（2025.08）

字节 Seed 团队联合浙大、上海交大开源 M3-Agent：

  • 像人类一样能听会看，具备长期记忆
  • 双过程架构：记忆过程（实时构建事件记忆 + 语义记忆）+ 控制过程（基于记忆推理执行任务）
  • 通过 强化学习训练检索策略，而非盲目的 RAG 检索
  • 配套开源 M3-Bench 长视频问答基准
  • 表现超越 Gemini-1.5-Pro 和 GPT-4o 构建的智能体

核心洞察：以实体为中心的多模态记忆至关重要；检索推理优于单次 RAG。

4.2 京东 JoyAgent 多模态 RAG 开源（2025.12 更新）

  • GitHub 11.2k Star
  • 开源多模态 RAG 能力：支持图片、表格等多模态知识管理
  • 解决传统 RAG 只能处理文本的局限

4.3 GUI 智能体成为手机厂商竞争焦点

十一、趋势洞察与展望

洞察 1：前沿模型正在「基础设施化」

GPT-5 的低价策略标志着一个拐点——前沿能力不再是稀缺品，而是可大规模采购的基础设施。AI 行业的利润中心正在从「卖模型」向「卖应用」转移。2025 下半年 AIGC 产业 186 起投融资中，下游应用层接近 50%。

洞察 2：开源生态进入「全栈竞争」时代

OpenAI 重返开源 + Qwen3-Coder 完整工具链 + M3-Agent 多模态智能体开源 = 开源不再是「追赶闭源」，而是在多个维度主动设定行业标准。Apache 2.0 许可证的普及进一步降低了商业化门槛。

洞察 3：多模态是唯一共识

纯语言模型能力接近触顶（权威预测 2028 年耗尽人类文本数据）。商汤、MiniMax、阶跃星辰、字节等团队的实践表明：多模态融合（视觉 + 语言 + 音频 + 3D）才是通向 AGI 的正确路径。

洞察 4：Agent 从对话走向自主执行

从 Qwen3-Coder 的代理式编程，到 M3-Agent 的长期记忆推理，到 GUI 智能体的「跨 App 无感串联」——AI Agent 正在从「回答问题」进化到「自主完成任务」。

洞察 5：具身智能进入「量产元年」

万台订单标志着人形机器人从实验室走向工厂、医院、酒店。端到端具身大模型（VLA）成为核心技术分水岭。2025 年下半年上新的 205 个 AI 应用中，具身智能是增长最快的赛道之一。

洞察 6：安全治理与技术创新同步加速

中国《AI 安全治理框架》一年内从 1.0 迭代到 2.0，联合国建立全球 AI 治理机制。「敏捷治理」理念正在成为全球共识——治理不是创新的对立面，而是可持续发展的保障。
