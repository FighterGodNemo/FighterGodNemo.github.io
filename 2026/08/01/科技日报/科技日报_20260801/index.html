科技日报 - 2026年8月1日 星期六

关注方向：AI Coding · 具身智能 | 精选 5 条

1. DeepSeek V4-Flash 正式版上线：纯后训练将 Agent 能力拉升 7.5 倍

事件： DeepSeek 于 7 月 31 日发布 deepseek-v4-flash 正式版 API 公测。模型结构与参数规模（284B MoE，激活 13B）完全不变，仅通过重做后训练，实现了 Agent 能力的飞跃式提升——Terminal Bench 从 56.9 升至 82.7（+25.8 分），Toolathlon 从 51.8 升至 70.3（+18.5 分），DeepSWE 从 7.3 升至 54.4（涨 7.5 倍）。

关注原因： 这证明了「后训练放大 Agent 能力」是一条极高性价比的路线——不需要堆更大的模型，仅靠针对性训练就能让编程 Agent 能力脱胎换骨。对于 AI Coding 工具来说，这意味着未来模型迭代可能更快、成本更低。DeepSWE 的 7.5 倍提升尤其值得关注，它直接关系到 AI 自动修 Bug、自动提交 PR 等软件工程场景的实用化进程。

2. Y Combinator 开源多人 Agent 编程框架 qm

事件： YC 软件部门正式开源 qm（MIT 许可），这是一个面向企业团队的多玩家 Agent 工作台。每个员工拥有独立沙箱和专属记忆，可在 Slack 频道、群组和项目中与 Agent 协同工作，支持在 Pi、OpenCode、Claude Code 等不同编程工具间自由切换。

关注原因： 这是「Agent 进入团队协作」的标志性事件。qm 不只是又一个编程助手，而是把 Agent 变成了团队的「数字同事」——有独立工作空间、共享技能库和审计追踪。YC 从自身经验提炼出的这套框架，可能加速 AI Coding 从「单人提效」到「团队协作范式」的转变。MIT 开源意味着任何团队都能立即部署。

3. Google DeepMind 发布 Gemini Robotics 2：「全身智能」时代到来

事件： Google DeepMind 于 7 月 30 日发布 Gemini Robotics 2 模型套件，包含视觉-语言-动作（VLA）模型，首次实现人形机器人「全身智能」控制——从脚底到指尖的协调运动。新模型可在数小时内适配不同机器人身体形态，展示灵巧手部操作和跨机器人平台协同作业。合作伙伴 Apptronik 的人形机器人已成功演示。

关注原因： 这是具身智能从「会走」到「会干活」的关键跨越。传统机器人控制是分模块的（腿归腿、手归手），Gemini Robotics 2 的「全身控制」意味着 AI 开始理解身体的整体协调性——这更接近人类的运动智能。数小时适配新身体形态的能力，则大幅降低了不同机器人平台的部署门槛，可能加速人形机器人的场景落地。

4. 国产首款具身智能专用 GPGPU「天衡 1100」发布

事件： 速显微电子在天津发布国内首款面向物理 AI 与具身智能端侧场景的 GPGPU 芯片「天衡 1100」，搭载自研 TUCA 统一计算架构，拥有 100T 算力。与云端训练 GPU 不同，天衡 1100 专为端侧低功耗实时推理设计，采用「先渲染后 AI」的开发逻辑，瞄准人形机器人、四足机器人等具身智能终端的片上计算需求。

关注原因： 具身智能的算力瓶颈不在云端，而在端侧——机器人需要在极低功耗下完成实时感知、推理与决策。天衡 1100 填补了国产芯片在这一细分领域的空白。在 FCC 刚禁止中国新型人形机器人进口美国的背景下，具身智能核心芯片的自主可控显得尤为关键。这标志着中国具身智能产业链从「本体制造」向上游「算力芯片」延伸。

5. Claude Mythos Preview 自主发现后量子密码学弱点：AI 开始「破译」加密算法

事件： Anthropic 披露其未发布模型 Claude Mythos Preview 在密码学领域的突破性成果：在约 60 小时半自主 Agent 框架运行中，成功发现 NIST 后量子签名候选算法 HAWK 的数学弱点（将密钥强度减半），并开发出「Möbius Bridge」技术加速 AES-128 攻击（提速 800 倍）。两项成果均由非密码学专家的研究员协调完成。

关注原因： 这不仅关乎 AI Coding 的能力边界——AI 开始从「写代码」进化到「发现算法弱点」，触及计算机科学的底层。对于 AI Coding 工具而言，这意味着未来的编程助手可能不只是帮你写 CRUD，还能协助发现系统中的安全漏洞、优化密码学实现。当然，这也带来了新的安全挑战：同样的技术可能被用于攻击。AI 辅助密码学研究的时代已经到来。
