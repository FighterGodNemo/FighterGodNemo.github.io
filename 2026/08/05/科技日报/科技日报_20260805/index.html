二、大模型前沿

2.1 OpenAI GPT-5：统一推理架构落地

2025年8月7日，OpenAI 发布 GPT-5——首个将「聊天模式」与「推理模式」合二为一的旗舰模型。核心亮点：

  • 混合推理路由：模型自行判断问题复杂度，简单问题快速响应，复杂问题自动深度推理，无需用户手动切换
  • 400K Token 上下文窗口：单次可处理整本长篇小说级别的输入
  • 幻觉大幅降低：相比 GPT-4o 幻觉率降低约 45%，思考模式下相比 o3 降低约 80%
  • 定价激进：API 定价低于市场预期，将「前沿能力」推向「commodity」级别

2.2 腾讯混元 Hyra：AI 数学家的高光时刻

2026年7月底，腾讯混元科研智能体 Hyra（基于 Hy3 大模型）仅用 24 小时攻克了加法组合学领域一道延续 50 余年的和差集公开难题，将最优指数推进至理论极限值 2。

紧接着 2026年8月初，OpenAI 披露其测试模型已解决或推动解决 10 道长期未解的数学问题，横跨高维几何、编码理论、群论等多个领域。

范式转变：AI 在科研中的角色正从「辅助计算工具」升级为「科研参与者」。Hyra 的工作方式更接近人类数学家——提出猜想、尝试不同路径、分析失败原因、总结中间结论、调整方向，而非简单检索或暴力搜索。

2.3 DeepSeek V3.1：迈向智能体时代

2025年8月21日，DeepSeek 发布 V3.1，核心升级：

  • 混合推理架构：思考模式 / 非思考模式自由切换
  • Agent 能力大幅提升：工具调用和智能体任务表现显著增强
  • 国产芯片适配：UE8M0 FP8 针对即将发布的下一代国产芯片设计
  • API 价格同步上调（自9月6日起）

2.4 Anthropic Claude Opus 4.1

2025年8月5日发布，聚焦 Agent 任务和真实编程场景：

  • SWE-bench Verified 达到 74.5%（当时 SOTA）
  • 同价同窗（200K），纯能力提升
  • 对已有 Claude 管线可「改一个 model string 即升级」

2.5 Google DeepMind Genie 3

2025年8月5日发布——通用交互式世界模型：

  • 文本输入 → 可实时导航的 3D 环境（720p / 24fps）
  • 环境持续性从 Genie 2 的 10~20 秒跃升至数分钟
  • 物体持久性「涌现」而非显式编程
  • 被视为 AGI 路径上的里程碑和具身智能训练场
