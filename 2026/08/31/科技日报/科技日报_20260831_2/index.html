科技日报 - 2026年8月31日 星期一

关注方向：AI Coding · 具身智能 | 精选 5 条

1. Uber 技术长文：70% 代码 PR 已由 AI Agent 接管，AI 账单不升反降

事件： Uber 工程团队发布技术长文披露内部数据：全公司超过 70% 的 Pull Request 已由本地或云端 AI Agent 生成/关联，Agent 日执行量突破 3 万次，周请求量半年内增长 9.4 倍，内部已沉淀 3,600 多个 Agent skills。更关键的是，在调用量暴涨近 10 倍的情况下，公司 AI 总支出自 4 月起基本持平，单次会话成本下降 52%。

关注原因： 这是 AI Coding 从「尝鲜」走向「规模生产」的最强实证。此前各家 Demo 都是单点展示，Uber 给出的是真实企业在生产环境下的全量数据：Agent 已占据软件生产的主流，同时通过缓存、模型路由和 skill 复用把成本压了下来。Uber 的模式证明了「AI 账单可控的大规模 Agent 化开发」不是口号——这会成为全球软件工程团队复制和追赶的样板，也回答了「AI Coding 到底是不是生产力」这个最根本的问题。

2. 英伟达 129 亿美元收购 Hugging Face + 开源机器鸭 Microduck：从模型分发到动作技能分发

事件： 8 月 26 日英伟达确认以约 129 亿美元收购全球最大开源 AI 模型社区 Hugging Face（对应约 86 倍市销率，较 2023 年 45 亿美元估值增长近两倍，刷新英伟达收购纪录）。紧接着 8 月 27 日，Hugging Face 旗下法国机器人公司 Pollen Robotics 推出 Microduck——25cm 双足开源机器鸭，15 个电机 + 相机 + LiDAR + 可抓取的喙，售价仅 399 美元，7 小时销售额破百万美元，全栈代码已在 GitHub 开源。

关注原因： 英伟达买下的不是现金流而是「分发权」——Hugging Face 是模型与数据集的分发枢纽，129 亿美元买的是 AI 生态的入口。而 Microduck 的出现则暗示了这条链条的下一环：从「AI 模型分发」延伸到「AI 动作技能分发」。399 美元的定价 + 全开源，让人人可玩「物理 AI」成为现实，也是具身智能走向消费级/教育级的标志性产品。芯片帝国 + 开源社区 + 具身硬件的组合，正在重新定义 AI 的产业纵深度。

3. 字节豆包大模型 2.2 推迟发布：All in Coding 能力，年底对标 GLM-5.2 与 Kimi K3

事件： 字节跳动宣布原计划 8 月发布的 豆包大模型 2.2 推迟，内部希望用更充分的预训练和后训练专项提升编程、工具调用与 Agent 能力。Seed 团队已重组为四个一级部门并密集挖角人才，目标是在年底前让豆包的 Coding 能力产生类似智谱 GLM-5.2 和 Kimi K3 的行业冲击力。

关注原因： 这是中国大厂把「Coding 能力」摆到最高优先级的最明确信号。字节此前靠豆包工作、TRAE、扣子完成了 Agent 工具链的「组织 + 能力 + 品牌」三步整合，现在选择推迟发布来打磨底座模型的编程能力——说明「Coding 能力」已经成为下一代模型竞争的胜负手，而非加分项。结合腾讯混元、智谱、Kimi 的密集动作，中国模型厂商在 AI Coding 上的军备竞赛已全面进入白热化。

4. 优地机器人赴港 IPO：机器人赛道从「故事估值」转向「账本估值」

事件： 配送机器人厂商优地科技启动 H 股 IPO，拟发行 4,500 万股，发售价区间 14.45-19.55 港元，预计 9 月 9 日在港交所挂牌，市值约 60 亿至 81 亿港元。其商业模式覆盖整机销售、AI 视觉方案、RaaS（机器人即服务）及租赁，2023-2025 年收入连续增长、亏损持续收窄、毛利率改善。

关注原因： 这是具身智能资本市场「祛魅」的重要样本。与前两周宇树 219 倍 PE 的狂热定价不同，优地以「收入 + 毛利 + 亏损收窄」的账本逻辑赴港——市场正在从给「未来想象」定价，转向给「当期经营」定价。优地覆盖的配送、清洁等 B 端场景恰恰是具身智能最早跑通商业闭环的方向，它的挂牌表现将为一个完整周期（IPO 狂热 → 回调 → 价值回归）提供新的标尺。

5. 智谱开源 GLM-5.3：开源模型登顶智能体编程，追平闭源旗舰

事件： 智谱于 8 月 30 日开源 GLM-5.3 模型权重，支持本地运行与个性化定制，官方强调其擅长复杂编码、防御性网络安全和长程任务。在 AA 综合智能指数上取得 60 分，与 Claude Fable 5、GPT-5.6 Sol 等闭源旗舰同级，并与 Kimi K3 并列开源模型第一。

关注原因： 开源模型在「智能体编程」这一最关键的 AI Coding 场景上追平闭源旗舰，是本周开源阵营的又一颗信号弹——继腾讯混元 Hy4 反超 DeepSeek 之后，智谱 GLM-5.3 进一步压缩了开源与闭源的差距。加上字节全力追赶，国产模型的 Coding 能力已形成「混元 + GLM + Kimi + 豆包」四强并进的格局，开发者可选的本地/私有化高质量编程模型正在快速增加。
