科技日报 | 2026-10-21

一句话结论：DeepSeek 开源内部推理引擎 DeepInfer、Google 开源 TorchTPU，推理底座全面走向开放；印度 CA eMudhra 八枚中间密钥泄露引发浏览器紧急封禁，供应链安全与 AI 安全成为今日主线。

1. AI 前沿

  • DeepSeek 开源 DeepInfer 推理引擎：以 Apache 2.0 许可发布服务其 V4.1-Flash 模型的内部高吞吐推理框架，并承诺未来模型代码一并开源；配套 deepseek-recipe 可在自托管环境复现 API 的 token 处理。来源：The Decoder/思否 AI 日报
  • Google 开源 TorchTPU：基于 PyTorch 构建的应用可直接迁移到 TPU 芯片运行、无需重写代码，紧随亚马逊前一日发布同类工具，算力生态之争蔓延至编译层。来源：Daily AI Thread
  • Mistral 发布 Voxtral 3 语音全家桶：包含三款转写模型、一款 TTS 模型与语音智能体 SDK，补齐从语音到文本再到语音代理的完整链路。来源：AI/TLDR
  • ElevenLabs 发布 Eleven Realtime v1 Max / v1 Mini：两款语音到语音模型，官方宣称 Big Bench Audio 得分 98.8%、响应时间 0.57 秒，可通过 OpenAI 兼容 Realtime API 调用。来源：TPS
  • NVIDIA 发布 Cosmos3-H-Dreams：世界基础模型，基于 CMR Surgical 临床胆囊切除术数据训练，可在单张 RTX PRO 6000 上实时生成动作条件化的手术视频，号称首个实时生成式外科手术仿真器。来源：TPS/HuggingFace
  • 小米 MiMo-V2.6-Pro 上线 WorkBuddy：支持 1M 超长上下文与全模态，Artificial Analysis 智能指数得分 46，面向专业、长程及复杂工作流提供 AI 能力，官方宣称全球开源第一。来源：快科技/网易
  • OpenAI 发布 GPT-6.1 Sol：面向智能体编码与企业工作流，COBOL 代码翻译测试准确率 86.6%（GPT-5.6 Sol 仅 5.4%）。来源：TechNewsReel

板块洞察：推理框架与编译工具的开源让”模型自由”延伸到”算力自由”，语音、机器人、医疗等垂直领域的实时生成模型密集落地，AI 正从聊天走向具身执行。

2. 安全漏洞

  • eMudhra 八枚中间 CA 密钥泄露：攻击者可借此为任意网站伪造可信 HTTPS 证书；Chrome 在 100 分钟内按 SPKI 哈希封禁受影响中间证书，Mozilla OneCRL 与 Go 亦紧急阻断，私钥可由公开证书秒级恢复、无法靠软件更新修复，影响面持续清理中。来源：CyberSecBrief / Security Insights
  • Qilin/Inc 勒索软件利用 PAN-OS CVE-2026-0257：绕过 MFA 建立未授权 GlobalProtect VPN 连接，波及多个行业；德国警方逮捕一名与 Qilin 关联的俄罗斯籍嫌疑人。来源：CyberSecBrief / mlab.sh
  • OVHcloud CLI 发布版本被劫持：攻击者劫持贡献者 GitHub 账号，替换五个 CLI 发布版为窃取磁盘密钥的恶意构建，最长持续约 94 分钟。来源：OsintRep
  • AI 渗透工具被武器化：攻击者滥用 AI 渗透测试工具 Cairn 自动化入侵数百个网站（包括 John Deere、SharkNinja、Cummins 等）；此前 ARTEX AI 已被用于韩国银行多阶段攻击。来源：OsintRep
  • 瑞士养老金服务商遭网络攻击：超 100 名联邦雇员（含情报人员与精锐士兵）数据泄露；ETS 数据泄露暴露学生评估数据，Citizen Lab 记录 NSO Pegasus 间谍软件针对塞尔维亚官员。来源：Gazeta Express / mlab.sh

板块洞察：CA 密钥泄露意味着”信任根”被连根拔起，浏览器生态紧急联动成为唯一防线；AI 渗透工具的攻击自动化能力把漏洞利用周期压缩到分钟级，防御窗口显著收窄。

3. 开源与开发

  • DeepSeek 开源 DeepInfer 推理框架：Apache 2.0 许可，是服务 V4.1-Flash 的内部推理引擎，配套 deepseek-recipe 复现方案，标志头部推理栈走向开源。来源：The Decoder/思否
  • Railtown AI 开源 Railtracks Swift ADK：免费工具包让开发者构建 Apple 应用 AI 智能体，同时为 Conductr 平台获客铺路。来源：Markets Insider
  • Lights-On Software Factory 样板开源：基于 Claude Code 的自动化软件工厂脚手架，生产级 Votito 部署验证，宣称 token 成本降低 80%。来源：Emergent
  • PHP 维护者发布紧急警告与补丁：语言运行时存在两个关键漏洞，紧急安全版本已安排部署。来源：Cybersecurity Newsfeed
  • Perplexity 开源 AI Agent 安全沙箱 SPACE：为智能体提供隔离运行环境，宣称百次逃逸测试无一成功，面向 Agent 工作流治理。来源：FreeBuf

板块洞察：推理栈、语音栈、Agent 沙箱同日开源，开源社区正把”AI 生产链路”拆成可自托管的标准件；与此同时 PHP 等传统运行时紧急补丁提醒基础软件维护仍是安全底线。

4. 芯片与算力

  • Tenstorrent 完成 15 亿美元融资：将规模部署 Galaxy 服务器集群，继续服务开源权重模型（LLM 与视频生成），并推进 AI 与 CPU 协同算力。来源：DEV Community
  • TrendForce 预估 Q4 DRAM 合约价环比上涨约 20%：供应紧张、需求强劲，涨幅较 Q2（约 80%）、Q3（约 40%）放缓，DRAM 整体仍处价格高位。来源：科创板日报/新浪
  • 英伟达推动三星与台积电联手开发 HBM 基底芯片：NVHBM 基底芯片统一采用台积电 3nm、核心存储采用”1c”第六代 DRAM 制程，带宽最高提升 30%、功耗降低 15%，三星首次在 HBM 业务放弃全自主生产。来源：网易/镁客网
  • AI 封装热管理迈向千瓦级：生成式 AI 将芯片功耗与热流密度推至新高，AI 封装散热需求升至千瓦级，散热方案转向 die 级热设计。来源：DIGITIMES
  • 三星计划 2027 年全面进军硅光子学；台积电在台南增建 3nm 晶圆厂；瑞萨成立百人实体 AI 团队抢攻人形机器人芯片。来源：网易/TechSugar

板块洞察：算力投资持续加码（Tenstorrent 15 亿美元），存储涨价周期未见顶，供应链在英伟达主导下加速标准化——制程、封装、光互连正被纳入同一张路线图。

  • Google 将 Gemini Personal Intelligence 接入 Android Auto：可读取 Gmail、日历与照片辅助驾驶导航，默认关闭；但若用户曾在 Gemini 设置中开启过，该设置会沿用至车载场景，引发隐私讨论。来源：Daily AI Thread
  • Meta 数据合规三线并发：商业条款删”train”字样仍被指可爬取网站；法院令其披露批准下载盗版书籍的高管；6800+ 条 Muse 对话链接经公共 DNS 泄露。来源：Daily AI Thread
