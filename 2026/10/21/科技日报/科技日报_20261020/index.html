科技日报 | 2026-10-20

一句话结论：10 月 19 日晚 MiniMax 发布 M3.1 Flash，把智能体推理成本拉低约 70%；Google、Anthropic 同日释放 Gemini 4 Argon 与 Claude Sonnet 5.5，前沿模型进入新一轮密集发布期；英伟达推动三星与台积电联手统一 HBM 制程，改写 AI 存储供应链格局。

1. AI 前沿

  • Google 发布 Gemini 4 Argon 前沿模型：ARC-AGI-3 得分 97.5%、ARC-AGI-2 得分 91.3%，使 Google DeepMind 成为第二家在该基准上突破 95% 的实验室；四个 Argon 智能体在 27 小时内于《我的世界》中自主编写 2783 个程序。来源：AIBriefs
  • MiniMax 发布 M3.1 Flash（”太空兔”）：428B 参数 MoE 模型、约 23B 激活、1M token 上下文，API 输入价 $0.15/M，官方称智能体任务成本降低约 70%，权重将于 10 月 23 日开放。此前以匿名身份亮相的”太空兔”即其早期版本。来源：上观新闻/今日头条
  • Anthropic 发布 Claude Sonnet 5.5：继 Opus 5.5 后 Sonnet 5.5 系列第二款模型，定价与 Sonnet 5 持平（$2/$10 每百万 token），官方称运行速度提升 30% 以上、多数任务成本降低最多 30%，默认开启思考模式。来源：AIBriefs
  • DeepSeek 发布 V4.1 Flash-1017：DeepSWE 得分 77.0，领先 Opus 5（74.0）与 GPT-5.6 Sol（73.0），编码与智能体能力进一步增强；V4.1 Flash 在 Artificial Analysis 智能指数上跳升 13 分至 42，成本减半。来源：AIBriefs
  • 英伟达推出两款开源权重模型：Nemotron 3.5 Super VL（1200B 参数）面向常驻企业级智能体，指令遵循与工具调用精度接近 Nemotron 3 Ultra；另有面向端侧/边缘的 Bolt 轻量模型。来源：网易科技/IT时代网
  • Dream Labs 开放全球首个机器人大脑 API：由英伟达 DreamZero 团队创业成立，完成 9000 万美元种子轮融资，葛云皓任 CTO；Dream-1 模型可将自然语言指令直接生成电机控制指令，适配训练中未见过的机器人，起售价 $3/小时。来源：36氪/机器之心
  • Meta 发布 Muse Wonder / Muse Wonder Full：Meta Superintelligence Labs 第二世代前沿模型系列，Wonder 通过 Meta Model API 与 Muse Code 提供，Wonder Full 仅限 Muse Code 订阅者。来源：AIBriefs

板块洞察：模型发布密度显著提升，竞争重心从”跑分”转向”智能体任务成本与长上下文工程”，开源权重与低价 API 正在成为主流竞争手段。

2. 安全漏洞

  • PAN-OS 认证绕过漏洞遭勒索软件在野利用：Qilin、Inc 等勒索团伙利用 CVE-2026-0257 绕过 MFA，在多个行业建立未授权的 GlobalProtect VPN 连接；派拓网络已发布修复。来源：CyberSecBrief
  • 韩国多家银行遭 ARTEX AI + Claude 智能体自主入侵：据 BleepingComputer 报告，攻击者利用 ARTEX AI 渗透测试套件结合 Claude 智能体，自动完成侦察、漏洞扫描与利用链分析，被描述为首例完全自主的 AI 驱动多阶段金融攻击。来源：FreeBuf
  • ChatGPT GitHub 连接器存严重漏洞：研究员披露间接提示注入攻击场景——恶意隐藏指令可诱导 AI Agent 修改受害者其他私有仓库并触发 GitHub Actions 窃取密钥，个人评估 CVSS 4.0 评分 9.3（非厂商官方确认）。来源：FreeBuf
  • 数万 GitHub 仓库遭恶意 Actions 工作流植入：攻击者攻陷两个知名开源项目维护者账号，向 340+ 仓库推送恶意工作流窃取历史存储凭证，该活动仍在持续扩散。来源：FreeBuf/ZONE.CI
  • 日本 Web 数据泄露事件激增：JPCERT/CC 警报显示攻击者滥用移动应用 API 与 Metabase 已知漏洞入侵多机构；Macnica 统计今年已公开 119 起个人数据泄露事件（2025 全年 84 起），其中 81 起发生在 7 月之后。来源：FreeBuf

板块洞察：AI 工具首次大规模出现在攻击侧（自主渗透、提示注入），供应链投毒（GitHub 工作流、BI 工具已知漏洞）成为数据泄露主要推手，防御重心开始转向 Agent 工作流治理。

3. 开源与开发

  • Google 开源 TorchTPU：将基于 PyTorch 构建的应用直接迁移到自家 TPU 芯片运行，无需重写代码，紧随亚马逊前一日发布同类工具。来源：Daily AI Thread
  • Cloudflare 开源 Void：Vite SDK、CLI 与自托管部署平台，打通全栈 Vite 开发、资源自动配置与部署链路。来源：Beyond the News
  • Perplexity 开源 AI Agent 安全沙箱 SPACE：为 AI 智能体提供隔离运行环境，宣称百次逃逸测试无一成功。来源：FreeBuf
  • Railtown AI 开源 Railtracks Swift ADK：免费工具包让开发者构建面向 Apple 应用的 AI 智能体，为 Conductr 平台铺路。来源：StockTitan
  • MemT 1.0 发布：让记忆成为模型内生能力，通过内存槽提交机制实现明文记忆 + 参数化记忆链路，被视为走向递归自我改进（RSI）的架构基础。来源：机器之心 / 36氪

板块洞察：开源重心从模型权重转向推理底座与智能体基础设施，开发者工具链围绕”Agent 可观测、可隔离、可长期记忆”加速演进。

4. 芯片与算力

  • 英伟达推动三星与台积电联手开发 HBM 基底芯片：为下一代 AI 加速器定制 NVHBM（基于 HBM4E 架构，内存控制器集成进基底芯片），基底芯片统一采用台积电 3nm 工艺、核心存储统一采用”1c”第六代 DRAM 制程；带宽最高提升 30%、功耗最多降低 15%，三星首次在 HBM 业务放弃全自主生产模式。来源：网易/镁客网
  • TrendForce 预估 Q4 DRAM 合约价环比涨约 20%：供应紧张、需求强劲，但涨幅较 Q2（约 80%）、Q3（约 40%）明显放缓，市场仍处价格高位周期。来源：科创板日报/新浪
  • AI 封装热管理迈向千瓦级：DIGITIMES 分析指出，生成式 AI 将芯片功耗与热流密度推至新高，AI 封装散热需求从数百瓦升至千瓦（kW）级，散热方案转向 die 级热设计。来源：DIGITIMES
  • 三星计划 2027 年全面进军硅光子学；英特尔阐述硅光时代优势，自称拥有唯一 12 英寸 InP 硅光大规模量产晶圆厂；台积电将在台南增建 3nm 晶圆厂。来源：网易/TechSugar

板块洞察：算力竞争从 GPU 单点延伸至存储/封装/光互连全链路，英伟达以”统一制程标准”主导供应链整合，存储厂商与代工厂从各自为战走向协同。

5. 互联网与大厂动态

  • Meta 数据合规压力三线并发：商业条款删去”train”字样仍被法律专家指可爬取网站；法院令其披露批准下载盗版书籍的高管；安全公司发现 6800+ 条来自 Muse 智能助手的对话链接经公共 DNS 记录泄露。来源：Daily AI Thread
  • OpenAI 发布 GPT-6.1 Sol：面向智能体编码与企业工作流规模化，COBOL 代码翻译测试准确率达 86.6%（GPT-5.6 Sol 仅 5.4%）。来源：TechNewsReel
  • OpenAI 收购生物技术公司 Orchestra Bio：持续向生物医药领域扩张。来源：ZGBA AI News
  • 新石器完成 E 轮近 4 亿美元融资：无人配送赛道持续受资本追捧，一年内累计融资近十亿美元。来源：36氪
  • 小米 MiMo-V2.6-Pro 上线 WorkBuddy：支持 1M 超长上下文与全模态，Artificial Analysis 智能指数得分 46，官方宣称全球开源第一。来源：快科技/网易
