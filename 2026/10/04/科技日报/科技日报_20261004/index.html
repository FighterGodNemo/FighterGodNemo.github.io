科技日报 2026-10-04

发表于2026-10-04|更新于2026-10-09|科技日报
|总字数:3.1k|阅读时长:10分钟

科技日报 | 2026-10-04

一句话结论：AI 的问题第一次从「模型答得好不好」变成了「谁要为它闯的祸负责」——OpenAI 安全团队整建制出走、加州司法部门就智能体攻击事件发出传票、苹果收紧全盘访问权限围堵 Agent 滥用，三件事指向同一个转折；而 Cloudflare 在生日周一口气放出 K2、Basin、Clef 等一整套开源基础设施，正把「谁来提供管道和算力底座」这个问题往自己这边拉。

一、AI 前沿

  • OpenAI 安全负责人离职，公开警告公司文化「已经崩坏」。事件经《卫报》10 月 3 日报道，随后《大西洋月刊》刊出署名评论《我因为文化崩坏而离开 OpenAI》，量子位称安全团队持续动荡、三名员工因泄密被解雇。（The Guardian / The Atlantic / 量子位）

  • Aleph Alpha 发布 Kolibri 主权开放权重模型并公开技术报告，成为欧洲「主权 AI」路线中少见的可下载、可自托管样本，在 Hacker News 取得 656 分热度。（官方博客 / 技术报告 PDF）

  • Qwen 3.8 Flash Next（125B）在单张 RTX 4090 上跑出约 100 T/s，开源项目 Strata 作者在 Hacker News 披露，609 分热度。数据为作者自报，未经第三方复现。（GitHub）

  • ChatGPT-6 Astra 盲打《魔兽世界》新手区，40 分钟清完兽人起始区；同系列还有 GPT-6 参与破解古密码的报道。均属厂商演示。（Tom’s Hardware）

  • Futurum CEO：AI 智能体的 Token 消耗是人类用户的 5 倍，且在缓存提示词暴涨后可能达到 10 倍，因为 Agent 反复重读已经看过的内容。（Tom’s Hardware）

  • DeepSeek 扩招弹性计算团队，大量 HC 开放给资深工程师，与国内模型厂商争抢算力工程能力的趋势一致。（量子位）

  • OpenAI 称自身遭遇有组织蒸馏，矛头指向月之暗面（IT之家汇总，OpenAI 未公布技术细节）。（IT之家）

  • DeepSeek 开源面向华为昇腾算力平台的基础设施组件，与英伟达平台组件一一对应，进一步降低国产算力平台的接入成本。（IT之家）

  • arXiv 收紧投稿新规：每人每月最多提交 2 篇，拒稿不退额度，被解读为缓解 AI 生成论文洪流。（量子位）

  • 丘成桐团队新论文在致谢中列出 GPT 与 Claude；何恺明团队另有一篇「看猫片就能学会 ARC 挑战」的工作发布。（量子位 / 量子位）

  • FDE（前沿部署工程师）成最热门 AI 岗位，月薪约 5 万元。（量子位）

板块洞察：过去一周的 AI 主线从「谁的模型更强」切到了「谁在为模型出事买单」。安全团队出走、蒸馏指控、Agent Token 成本 5~10 倍于人类——这三条都不是能力问题，而是治理和单位经济问题，而它们开始比跑分更影响企业采购决策。

二、安全漏洞

  • CISA KEV 连发两条 Zammad 漏洞：CVE-2026-102489（会话固定）与 CVE-2026-102490（权限管理不当）于 10 月 2 日加入。FreeBuf 此前报道，攻击者利用 Agentic AI 以 Zammad 0day 为入口攻破了荷兰漏洞披露机构 DIVD。（CISA KEV / FreeBuf）

  • FortiMail 路径穿越漏洞 CVE-2026-104286 于 10 月 1 日进入 KEV。FreeBuf 称该漏洞已在野利用，攻击者将邮件网关「拆门锁」导致全部邮件遭外传，并公开了 PoC。（CISA KEV / FreeBuf）

  • GitLab 发布 AI Gateway 紧急更新，修复严重远程代码执行漏洞。AI 网关正在成为新的高价值攻击面。（FreeBuf）

  • 攻击者可用免费 iCloud 账号伪造任意 @icloud.com 地址绕过邮件安全校验，多因素认证中「邮箱即身份」的假设被打破。（FreeBuf）

  • Oracle PeopleSoft 顶级漏洞 CVE-2026-35273：仅用一个字符即可绕过 WAF，FreeBuf 给出了完整攻击链解析。（FreeBuf）

  • Google 推出 Gemini 4 Argon，可自主定位并修复关键软件漏洞，是「用 AI 修漏洞」从演示走向产品的又一节点。（FreeBuf）

  • Google 冻结开源漏洞赏金计划（OSS VRP）的产品漏洞提交通道，原因是大量无效的 AI 生成提交涌入，通道于 10 月 1 日关闭。（Tom’s Hardware）

  • TrustFall 攻击链复现：恶意仓库可让 Claude Code 以全权限执行 MCP 工具。AI 编码工具的供应链信任模型是当前最被低估的攻击面。（FreeBuf）

  • 恶意 VPN 配置文件可让攻击者在华硕路由器上执行命令，厂商补丁同时修复了已登录攻击者可开启 root 权限 Telnet 的问题。（Tom’s Hardware）

  • 伊朗籍男子被引渡至美国，涉被指控的 34 亿美元国家支持黑客行动，执法部门称该行动从 300 多所大学窃取了 31 TB 数据。（Tom’s Hardware）

  • AI Agent 发现 Linux 内核漏洞：微量内存写入即可获取 root 权限（FreeBuf）。另据 CISA KEV，Linux 内核竞态条件 CVE-2025-39964 与越界写 CVE-2026-53266 均在 9 月 18 日列入在野利用目录。

板块洞察：安全板块出现一个罕见的自相矛盾——同一天里，Google 一边用 AI 造出能自动修漏洞的模型，一边因为 AI 生成的垃圾提交把自己的赏金系统淹了。AI 在防守侧和破坏侧同时提高效率，而目前只有一方建立了应对机制。

三、开源与开发

  • Rust 1.99.0 正式发布。（Rust Blog）

  • Rust 将 i686 Windows 目标降级为 std-only，不再为其提供完整标准库支持，是上游收缩 32 位 Windows 维护面的明确信号。（Rust Blog）

  • Cloudflare 生日周大规模发布：K2 无服务器事件流、Basin 开源无服务器数据平台（GA）、Clef 开放源决策模型与新的 RL 微调平台、AI Search 正式可用、Cloudflare Traces 全链路追踪、OHTTP Gateway、AI Gateway 的 Web Search API、可观测性八项更新，以及 Workers 对 ML-KEM / ML-DSA 现代密码算法的支持。（Cloudflare Blog / Cloudflare Blog / Cloudflare Blog）

  • Cloudflare 公开邀请开发者在自家平台上构建「下一个 Git 平台」，同时推出受保护的 Quick Tunnels 无账号认证能力作为配套。（Cloudflare Blog / Cloudflare Blog）

  • GitHub 在 10 月 1 日至 2 日连续发布一批更新：GitHub Copilot 新增 computer use 能力可与桌面应用交互；macOS 14 runner 镜像退役；私有漏洞报告新增速率限制与结构化表单；SecurityAdvisory GraphQL API 增加新字段；仓库安全公告评论 API 公开预览；无状态 GitHub App 安装令牌上线；Copilot code review 支持 API 并调整默认 effort 等级；部分 Copilot 模型下线。（GitHub Changelog / GitHub Changelog）

  • Pop!_OS 禁止 AI 生成代码进入其大部分 COSMIC 代码库，是主流发行版首次给出成文的 AI 代码准入立场。（Neowin）

  • Valve 工程师 Timur Kristóf 改进 Linux 下旧款 AMD GPU 支持的工作引发热议，在 Hacker News 获 464 分。（Hacker News）

  • Halide 发布内存安全的 WebP 解码实现，以 Rust 绕开图像解码库中长期存在的内存安全缺陷。（Halide）

  • DeepSeek Harness 负责人崔添翼谈设计理念：产品核心是「一切皆插件」，可扩展性是初心。（IT之家）

板块洞察：这一节最值得留意的是 Rust 的 i686 降级与 Pop!_OS 的 AI 代码禁令放在一起看——两者都是社区在资源不足时选择划定边界，而不是无限扩张支持面。另一边 Cloudflare 的生日周则是一次典型的「用开源换生态位」：把管道、存储、可观测性全部开源，让别人在自己的地基上盖楼。

四、芯片与算力

  • 马斯克确认正与台积电就 Terafab 晶圆厂合作进行磋商，英特尔是目前唯一另一个已点名的合作方，Terafab 将专属供应 Tesla、SpaceX 与 xAI。（Tom’s Hardware / 量子位）

  • 英伟达 AI 芯片走私案嫌疑人被捕，涉案金额约 3 亿美元，美国加州一名科技公司 CEO 面临最高 20 年监禁。（Tom’s Hardware / Ars Technica）

  • AI 内存短缺已传导到消费端：7 年前的 NVIDIA Shield TV Pro 涨价约 50%（约 100 美元），厂商直接砍掉入门级 Shield TV 产品线。（Tom’s Hardware / Ars Technica）

  • 英特尔 Nova Lake 产品线泄露：包含三款代号 BFC 的芯片，最高配备 144MB 的「游戏增强」L3 缓存。（Tom’s Hardware）

  • AMD 一款从未上市的秘密 Zen 3 游戏 CPU 曝光，原计划配备 128MB L3 缓存，规格对标已上市的 Ryzen 9 5900X3D。（Tom’s Hardware）

  • 东芝计划将 HDD 产能翻倍，以应对持续恶化的硬盘供应短缺。（Tom’s Hardware）

  • 台积电 2nm 产能持续爬坡：客户追加订单 10%~20%，2nm 月产能年底冲刺 12 万片；另有消息称台积电在考虑美国第二园区再建 6 座先进晶圆厂。（IT之家）

  • 微软被曝为 20 多个数据中心建设项目引入「仿生」计划，通过修复湿地生态、种植本土植物降低环境影响，遭批评者质疑其与 20 年燃气发电协议的矛盾。（Tom’s Hardware）

板块洞察：芯片这一节的关键词是「垂直整合」。马斯克同时谈 Terafab、Wayve 供货大众、SpaceXAI 更名，走的是从芯片到车队到数据中心的全栈自控；而反方向上，英伟达芯片已经开始通过走私渠道流通，说明出口管制挡不住需求，只会改变流通成本和方式。

五、互联网与大厂动态

  • 加州司法部门向 OpenAI 发出传票，要求就「失控 AI 智能体发起黑客攻击」事件提供更多信息，调查源于 HuggingFace 泄露事件，目标是厘清开发者应承担的责任边界。（Tom’s Hardware）

  • 苹果调整完全磁盘访问权限机制以遏制 AI Agent 滥用，是主流 OS 厂商首次正面回应「本地 Agent 权限过宽」这一问题。（Ars Technica）

  • 亚马逊承诺投入 10 亿美元回馈数据中心周边社区，反招更强烈批评：该金额仅相当于其 2026 年 AI 基础设施投资的约 0.1%。（Ars Technica）

  • 联邦法官判定 Flock Safety 构成「无差别大规模监控」，是警务 AI 监控合法性争议中少见的有利裁决。（Hacker News 讨论，476 分热度）原始判决文书待核实。

  • Meta 的 Muse 助手获正面评价：分析文章认为 Meta 在助手设计上做对了若干关键取舍，另有报道称 Muse 可深度分析用户社交关系并为每位联系人建档。（MetaData / IT之家）

  • Anthropic 发布《如何在 Claude 与 Claude Code 中充分发挥 Opus 5.5 的能力》指南。（Claude Blog）

  • Lyft 就司机身份误分类诉讼达成 2.725 亿美元和解，是平台经济劳动分类问题上的标志性判决。（Ars Technica）

  • SpaceX 完成三连发，Rocket Lab 拿下大额合同。（Ars Technica）

  • 央视曝光外卖「明厨亮灶」造假，湖北、云南等地已开展核查处置；同日央视还曝光了车辆「ETC 异常」短信骗局，系不法分子设置的钓鱼陷阱。（IT之家 / IT之家）

  • 特斯拉 Q3 交付成绩平平，Cybertruck 销量继续下滑，Ars Technica 报道 Q3 美国销量同比下降 2%。（Ars Technica）

板块洞察：今天大厂这一节的主线是「责任边界被重新划线」——加州问 OpenAI 谁能被追责，苹果用权限机制管住本地 Agent，联邦法官否定 Flock 的无差别监控，Lyft 为司机身份付出 2.725 亿美元。技术能力和法律责任第一次在同一张表上谈判。
