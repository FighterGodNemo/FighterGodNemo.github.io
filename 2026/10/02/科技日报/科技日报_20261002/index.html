科技日报 2026-10-02

发表于2026-10-02|更新于2026-10-09|科技日报
|总字数:2k|阅读时长:6分钟

科技日报 | 2026-10-02

一句话结论:Google 新旗舰 Gemini 4 Argon 以「安全牌」重返前沿模型竞争,同期 OpenAI 因安全顾虑推迟发版、美国 FTC 对 OpenAI 与 Anthropic 启动调查——前沿 AI 的竞争焦点正从「跑分领先」转向「谁更可信」。

一、AI 前沿

  • Google 发布 Gemini 4 Argon,宣称部分基准超越 OpenAI 与 Anthropic:新模型于 9 月 30 日前后亮相,在 Artificial Analysis 智能指数中仅次于 Claude Opus 5.5 与 Claude Sonnet 5.5,单次输出上限号称达 100 万 token(厂商自报),将先面向安全合作伙伴分阶段开放,暂未公布全面开放时间(CNBC、53AI)。
  • OpenAI 推迟 GPT-6.1 Astra 发布:据 WSJ 等报道,OpenAI 以安全评估为由搁置了这款下一代模型的按期发布,与 Anthropic 近期「模型发布前先做政府侧安全评估」的做法趋同(WSJ)。
  • FTC 调查 OpenAI 与 Anthropic:美国联邦贸易委员会正调查两家公司是否存在消费者欺骗行为,监管与安全叙事正在直接影响头部实验室的发版节奏(WSJ)。
  • LeCun 团队提出自适应隐空间世界模型 AdaJEPA:机器之心本周报道了这一面向世界模型路线的新工作,延续 JEPA 系列对隐空间预测的探索(机器之心)。
  • Google DeepMind 同步放出新小的多款模型:包括图像/多模态方向的 Nano Banana 2 Lite 与 Gemini Omni Flash,延续「旗舰 + 轻量梯队」的产品化打法(机器之心)。
  • MiniMax 发布 M3.1 Flash:主打文字与图像同模型联合训练路线,宣称具备对标旗舰模型的关键能力(厂商自报)(搜狐科技)。
  • 开源权重模型安全评测引关注:据 AI Weekly 引述,Anthropic 报告开源权重 GLM-5.3 在端到端漏洞利用测试中 410 次尝试成功 50 次,接近其内部模型水平(待核实)(AI Weekly)。

板块洞察:一周内「发版」与「不发版」都成了新闻——模型能力竞赛仍在继续,但安全评估、监管审查正在成为新的发布门槛,头部厂商开始把「可信」当作产品卖点而非合规负担。

二、安全漏洞

  • Citrix NetScaler 两个高危漏洞在野利用,补丁不清除 Web Shell:CVE-2026-88771/88772 为预认证命令注入类漏洞,10 月 2 日多方确认正被积极利用;研究人员警告仅打补丁无法移除攻击者已植入的 Web Shell,需排查持久化(Computing、Hard2Bit)。
  • Cisco Catalyst SD-WAN 零日遭活跃利用:10 月 1 日披露的关键零日漏洞正被在野利用,边界网络设备成为近期的重点攻击面(Infosecurity Magazine)。
  • Fortinet FortiMail 零日被列入 CISA KEV 目录:CVE-2026-104286 为 CVSS 9.8 的路径遍历漏洞,CISA 给联邦机构的修复期限为 10 月 4 日,邮件网关类设备风险陡增(待核实)(LinkedIn 安全社区)。
  • Warlock 勒索组织扩大 SharePoint 漏洞利用:该组织持续利用 SharePoint 漏洞攻击水务、电信、政府等关键基础设施,漏洞利用窗口期后移已成勒索攻击常态(SecurityWeek)。
  • 苹果确认 iPhone 18 Pro 存在 Face ID 相关严重系统漏洞:据 36氪报道,苹果证实该系列存在与 Face ID 相关的系统级问题,修复安排待官方进一步说明(待核实)(36氪)。

板块洞察:本周在野利用集中在「边界设备」——NetScaler、SD-WAN、FortiMail 轮番中招,且「打完补丁 ≠ 清除入侵」提醒企业把应急响应从补丁管理升级到取证排查。

三、开源与开发

  • Next.js 紧急安全发布:一次修复 9 个漏洞:9 月 30 日发布的安全版本覆盖 1 个严重、2 个高危、5 个中危、1 个低危漏洞,使用 Node Web 框架的团队应尽快升级(官方发布公告,待核实具体编号)。
  • Linux 内核容器逃逸漏洞 CVE-2026-80521 已有公开 Exploit:内核 use-after-free 漏洞可导致容器逃逸,官方补丁已发布,多租户环境需优先处置。
  • GitHub 与 Anthropic 用自家 AI Agent 完成 Python→Rust 大型重写:双方披露借助编码智能体把 Habitat 项目从 Python 重写为 Rust,AI 驱动的大规模存量代码迁移正在从实验走向生产(The New Stack)。
  • GitHub Copilot 预览多模型编排「Project HydraFusion」:在运行时按任务调度多个模型以获得前沿级输出质量,编辑器内的「模型路由」开始产品化(GitHub Blog)。
  • GitHub Universe 2026 定档 10 月 28–29 日:主题聚焦「人类、智能体与代码」,预计将公布 Agent 开发工具链的下一阶段计划(GitHub)。

板块洞察:开源世界的两条主线正在合流——一条是「存量安全债」的集中清算(框架与内核接连紧急修复),另一条是 AI Agent 正式接管「重写/维护」这类最重的工程劳动。

四、芯片与算力

  • 台积电考虑在德州新建数十亿美元园区:彭博 10 月 1 日报道,台积电正评估在达拉斯一带建设第二座美国基地,以承接激增的 AI 芯片订单(Bloomberg)。
  • 2nm 订单全面升温:Apple、NVIDIA、AMD、高通、联发科合计拉升 2nm 订单 10%–20%,台积电 2nm 月产能有望在 2026 年底达到约 12 万片(供应链消息,厂商自报)。
  • NVIDIA 就 H200 新订单接触台积电,中国需求反弹:路透报道称中国企业据报已订购约 200 万颗 H200,中国市场需求回升正在改变 NVIDIA 的排产考量(Reuters)。
  • 英特尔押注「一颗 CPU 跑 1000 个智能体」:推出 KV Cache 智能加速套件(核心组件 KV Shrink),以三层结构优化智能体时代的 AI 推理内存占用(厂商自报)(36氪)。
  • 初创公司 Nuvacore 挑战传统 CPU 架构:36氪报道称其试图从头构建「面向智能体 AI」的处理器,认为现有 CPU/GPU 均非为 Agent 负载设计(36氪)。

板块洞察:算力叙事正从「训练堆卡」转向「推理与智能体负载」——台积电扩产解决的是供给侧,而 Intel 的 KV Cache 优化与 Nuvacore 的 Agent 原生芯片,瞄准的都是推理成本这条新主战线。

五、互联网与大厂动态

  • Amazon 承诺 10 亿美元反哺数据中心社区:AWS 警告「本地抵制」威胁美国 AI 领先地位;据 WSJ,Amazon、Microsoft、Google、Meta 今年合计资本开支约 7000 亿美元,绝大部分投向 AI。
  • Warren 参议员调查大厂 AI 税收减免:要求 Amazon、Google、Meta、Microsoft 就约 960 亿美元联邦税收流失作出说明,数据中心税收优惠成为政治焦点(Moneywise)。
  • Azure 与 AWS 将被纳入欧盟严格监管名单:继平台巨头之后,云基础设施开始进入欧盟「看门人」规则射程,合规成本将向 IaaS 层传导。
  • 腾讯低调上线 LightVela:36氪报道其轻量云团队推出该产品,托管开源 Hermes Agent,提供 7×24 小时在线的云端专属 AI(厂商自报)(36氪)。
  • 三星与 Naver 联合开发企业级生成式 AI:目标最早 10 月发布,韩系厂商试图以「本地化企业 AI」差异化对抗美系模型(36氪)。

板块洞察:大厂与监管的碰撞从「应用层」蔓延到「基础设施层」——数据中心选址、税收优惠、云市场监管三线并进,算力扩张的政治成本正在显性化。
