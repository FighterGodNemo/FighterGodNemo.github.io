科技日报 2026-10-15

科技日报 | 2026-10-15

一句话结论：今天最值得记的一件事是「国产开源模型 + 国产算力的 Day-0 同步」 becoming 常态——阶跃星辰一开源 Step 5 Preview，华为昇腾、壁仞、沐曦、摩尔线程四家同日宣布 0Day 适配，昇腾还顺手点亮了首套 1024 卡 Atlas 950 SuperPoD 超节点；另一条线是 Anthropic 宣布弃用 Git 自研版本控制系统 Scion，AI 智能体的代码规模已经涨到把 Git 挤下桌的程度。

一、AI 前沿

  • 阶跃星辰开源 Step 5 Preview 模型权重，包含 BF16 与 FP8 两个版本，官方称在 AI 编程、软件工程、专业知识工作、金融等任务上达到前沿水平，支持 100 万 token 上下文窗口，权重已上线 Hugging Face 与 ModelScope。来源：IT之家
  • 华为昇腾、壁仞科技、沐曦股份、摩尔线程同日宣布 Day-0 支持：昇腾基于 vLLM 推理引擎实现 0Day 支持并做了针对模型架构与硬件特性的推理优化；沐曦称曦云 C 系列 GPU 率先完成 Day 0 深度适配，自 2025 年 12 月以来已完成 43 个主流旗舰模型的 Day 0 适配。来源：IT之家
  • DeepSeek 全球服务中断近 5 小时：官方开放平台公告称北京时间 2026 年 10 月 15 日 08:11 至 13:04 服务系统出现故障，API 无法正常使用；将按账号 7 日内（10.8—10.14）的消耗金额以赠金形式全额返还，赠金自动到账。官方称已启动稳定性排查并「全面梳理并剥离单点依赖」。来源：IT之家
  • 库克确认 Apple Intelligence 月底在中国发布测试版，但明确不包括 Siri AI；接入方为阿里通义千问。彭博社另称苹果有望 12 月随 iOS 27.3 在中国大陆推出首波 Apple Intelligence 功能。来源：IT之家、IT之家（彭博社）
  • 苹果 AI 国内供应商浮出水面：阿里、百度，消息称 12 月随 iOS 27.3 上线；同期国行 iPhone 15 Pro 及后续机型完成大模型备案，备案编号包含 Apple 智能、通义万相、通义千问。来源：IT之家、IT之家
  • DeepSeek 投了 Swin Transformer 作者，布局具身智能「大脑」；另有前华为小艺大模型负责人创业押注「主动式物理 AI」、国内最年轻 AI 教授创业做「全身全模态世界模型」。来源：量子位、量子位、量子位
  • 智谱新模型推理速度达 490 tokens/s（10 月 12 日报道）。来源：量子位
  • 中国团队把游戏世界模型塞进单张 RTX 5090 并开源。来源：量子位
  • 国产开源多模态新模型可在 iPhone 断网跑 35B，内存占用约 3G。来源：量子位
  • 工信部发布人工智能「产业导师」相关部署，覆盖 1000 余个场景。来源：网易科技
  • 阶跃星辰发布首款「Agent 手机」STEPX Neo / STEPX 创客版，主打 Agent 原生交互。来源：量子位
  • 报道称国内约一半 AI 算力被指用于内容生成（拍爽剧），用于研发仅约 15%（媒体引述口径，待核实原始调研来源）。来源：网易科技
  • Gartner 警告 AI 投资热潮暗藏风险，涉及规模逾 3.5 万亿美元。来源：网易科技
  • 两家大厂接连挖人，一家明星 AI 公司申请破产保护。来源：网易科技

板块洞察：今天 AI 板块的重心明显从「刷榜」转向「能不能真部署」——DeepSeek 用近 5 小时宕机和单点依赖事故提醒了规模化的运维代价，而国产四家芯片厂同日 Day-0 适配、昇腾 1024 卡超节点同步点亮，则说明开源权重发布正在被当成国产算力的集体获客时刻，性能数字（1 EFLOPS FP8）目前均为厂商自报口径，实际吞吐仍需第三方压测验证。

二、安全漏洞

  • CISA 已知被利用漏洞目录（KEV）发布 2026.10.14 版本，当日新增 6 条在野利用漏洞，目录累计 1745 条：Ahsay AhsayCBS 命令注入 CVE-2026-105134、Ahsay AhsayCBS 不当身份认证 CVE-2026-105133、Cisco Secure Email Gateway 相对路径遍历 CVE-2026-76519、Palo Alto Networks PAN-OS 代码注入 CVE-2026-0322。来源：CISA KEV JSON Feed
  • 10 月 13 日再增两条：Ivanti Connect Secure 身份验证绕过（欺骗）CVE-2026-104935、Microsoft Windows 命令注入 CVE-2026-96951。以上条目 CISA 标记的勒索软件利用情况均为 Unknown。来源：CISA KEV
  • KEV 于 10 月 8 日一次性补录一批高危老漏洞，涉及 ISC BIND 数据处理错误 CVE-2015-5477、Apache Struts 命令注入 CVE-2016-3081、Strapi 敏感信息明文存储 CVE-2023-22894、ONLYOFFICE Docs Server 路径遍历 CVE-2021-3199、ProFTPD 访问控制不当 CVE-2015-3306——属于典型的「扫描器打满即被打标」现象。来源：CISA KEV
  • 研究：Unlearning 攻击可通过「遗忘」机制绕过 LLM 安全对齐（FreeBuf 实测研究文章，属攻防研究非厂商公告）。来源：FreeBuf
  • 实录：Agent 自主不间断渗透 100 小时完整战报，公开了长时程智能体在真实攻防中的执行模式。来源：FreeBuf
  • AI 应用 API 安全测试实录：从信息泄露到未授权调用。来源：FreeBuf
  • 多模态大模型越狱攻击与防御技术综述（从围堵走向封杀）。来源：FreeBuf
  • 疑似 AI 冒充真人客服电话推销被识破，反映语音克隆式诈骗的落地风险。来源：网易科技
  • 赛力斯起诉发布 AI 视频造谣者，索赔百万元。来源：IT之家
  • Ubuntu 26.10 安全面更新：采用 OpenSSL 4（支持 ECH、扩展 QUIC、推进后量子密码）、GNOME 51 移除 WEP 无线加密支持、TPM 全盘加密（FDE）现可在无硬件信任根设备上安装（需配合 PIN 或口令）、企业身份集成支持 Microsoft Entra ID 口令与 MFA 登录。来源：IT之家

板块洞察：本周安全线的核心信号是「边界设备」——PAN-OS、Cisco SEG、Ivanti Connect Secure 在两天内连中三条，说明绕过攻击正集中打击网络边界而非终端；同时 CISA 开始批量补录十几年前的经典漏洞，防守方的实际负担不是新漏洞数量，而是历史欠账的批量暴露面。

三、开源与开发

  • Ubuntu 26.10 正式发布，代号 “Stonking Stingray”：作为 26.04 LTS 之后的过渡版本获 9 个月支持（至 2027 年 7 月），搭载 GNOME 51 与 Linux 7.3（首发镜像因上游最终版未就绪基于 7.3-rc6 构建），图形栈更新至 Mesa 26.2。来源：IT之家
  • Ubuntu 26.10 完成 Rust 核心工具的全面迁移：默认命令行工具已 100% 运行在基于 Rust 的 uutils 实现之上，此前为兼容性保留的最后三个 GNU 命令 cp、mv、rm 在本次发布中完成切换，Canonical 自 25.10 启动的过渡正式收官。来源：IT之家
  • Ubuntu 26.10 的硬件与架构扩展：新增对高通 Snapdragon X Elite / X2 Elite 笔记本的初步支持及部分 X Elite 机型内置摄像头驱动；首次提供 RISC-V 桌面镜像，支持 SpacemiT K3 与 SiFive BigSky 平台；App Center 新增独立驱动管理页可选择 NVIDIA 驱动分支。来源：IT之家
  • Anthropic 宣布弃用 Git，转用自研版本控制系统 Scion：官方称 5 月平均每天合并 2500 次代码变更，9 月已超过 3 万次，Git 无法满足需求；Scion 的 CPU 和内存消耗据称仅为 Git 的二百分之一，切换后 CI 与研究任务的代码检出仅需几秒而非数分钟。Scion 将提交、合并、变基和文件历史查询放在服务器端执行，客户端只跟踪本地修改、维护有限缓存。来源：IT之家
  • Anthropic 的 Scion 难以被直接复制：因需要配套定制代码审查、搜索与 CI 工具链（此为媒体分析视角）。来源：IT之家
  • 阶跃 Step 5 Preview 部署路径明确：权重在 Hugging Face / ModelScope，可用 vLLM 或 SGLang 部署兼容 OpenAI 接口的 API 服务，也可用 Transformers 离线推理。来源：IT之家
  • 国产开源模型工程化进展两项：游戏世界模型压进单张 RTX 5090 并开源；另一款多模态模型可在 iPhone 断网运行 35B、内存占用约 3G。来源：量子位、量子位
  • 百度世界 2026 定档 11 月 12 日，官方称将有重磅嘉宾与企业级 AI 产品集中亮相。来源：IT之家
  • 量子位智库发布 Agent 落地报告，拆解企业智能化六大断点并给出全链路破局框架。来源：量子位

板块洞察：Linux 基础栈正在完成一次静默但关键的地基替换——Ubuntu 把 cp/mv/rm 全部切到 Rust、移除 WEP、引入 OpenSSL 4 与后量子推进，这些都是安全债的偿还而非功能更新；而 Anthropic 的 Scion 则从另一侧印证了同一件事：当 Agent 每天提交三万次变更时，传统客户端-服务器版本控制模型本身已经成了瓶颈。

四、芯片与算力

  • 首套 1024 卡 Atlas 950 SuperPoD 液冷超节点随 Step 5 Preview 开源同步上线点亮，基于灵衢高速互联架构与超节点技术体系，官方称是业界规模最大的 1024 卡超节点产品，可提供 1 EFLOPS FP8、2 EFLOPS FP4 精度算力，面向万亿参数大模型推理场景。来源：IT之家
  • 昇腾 950 超节点关键指标（厂商自报）：256TB 全局统一内存编址能力、NPU 卡间达 TB 级互联带宽、时延低至 3μs；推理侧通过 vLLM Ascend 引擎与 Ascend C / Triton 融合算子、多流并行、计算空泡优化、MTP 投机解码、NPU Graph 图执行打通模型—算子—框架链路。来源：IT之家
  • SK 海力士拟以美国建厂换取大连工厂设备进口许可：路透社报道称，其美国子公司 Solidigm 希望在中国大连工厂尚未充分利用的 Mod B 厂区（2023 年建成）安装更多 NAND 生产设备，厂区设备来自泛林、应用材料、科磊等美厂，已申请出口许可证；Solidigm 同时在考虑美国新建 NAND 厂（纽约州北部为候选之一），最早可能 2027 年 IPO。SK 海力士回应称安装工作正与美方密切协商、并将在获授权后进行，同时强调目前并未寻求扩大大连 Mod B 产能。来源：IT之家（路透社）
  • 黄仁勋：英伟达在 AI 安全领域必须与中国企业合作。来源：IT之家
  • 沐曦曦云 C 系列完成 Step 5 Preview Day-0 深度适配，基于自研 XCORE 架构与 MetaXLink 片间互联，配套自研 MXMACA 全栈软件栈，官方称可将大模型适配周期从数周压缩至小时级。来源：IT之家
  • 壁仞科技完成 Day-0 适配：基于 vLLM 与 BIRENSUPA 软件栈在壁砺系列通用 GPU 上打通权重加载、服务启动、文本生成链路并完成精度验证；其全栈多智能体平台 SUPACODE 可自动解析适配 Step 5 Preview 的 DSA、SummaryCache 与 MoE 模块。来源：IT之家
  • 摩尔线程 MTT S5000 与 MUSA 软件栈完成 Day-0 适配与运行。来源：IT之家
  • MemSilicon 完成国际首款高密度大容量 1T4R 1Gb RRAM 芯片流片。来源：量子位
  • 报道称苹果、英伟达各捐 2500 万美元，为特朗普白宫宴会捐款名单中单笔最高金额。来源：IT之家
  • 商汤大装置称调度效率提升 80%，支撑上海量子城市首批智能体落地。来源：量子位

板块洞察：算力这条线的政治经济学权重今天压过了技术权重——SK 海力士用「美国建厂」换「大连扩产设备许可」的叙事，说明出口管制已经进入以产能投资做筹码的阶段；与此同时国产算力靠开源权重的 Day-0 适配窗口集体刷存在感，短期是生态卡位，长期仍取决于真实推理吞吐与总拥有成本。
