科技日报 | 2026-10-22

一句话结论：过去 72 小时最值得关注的是两件大事——英伟达 GTC 柏林大会上黄仁勋宣布从「卖 GPU」转向「卖 AI 工厂」、Vera Rubin 进入全面生产；同时 PHP 高危漏洞「PHP2Shell」（CVE-2026-109618 / CVE-2026-109619）被披露，补丁发布数小时内即出现野外利用，全球超百万台 PHP 服务器面临风险。

AI 前沿

  1. 黄仁勋 GTC 柏林主题演讲：AI 不是软件，而是制造业——10 月 21 日，英伟达 CEO 黄仁勋在 GTC 柏林发表 90 分钟主题演讲，系统阐述从「卖 GPU」向「卖 AI 工厂」的战略转向，并推出 OpenShell 参考架构与 DSXPOD 设计，将模型推理、智能体工具调用与安全管控分配到不同硬件。英伟达博客｜界面新闻
  2. Anthropic 发布 Haiku 5.5 并大幅降价——10 月 22 日消息，Anthropic 发布 Claude Haiku 5.5，并将 Sonnet 5.5 缓存读取价格减半至每百万 Token 0.10 美元，称多数智能体任务成本将降低约 20%；Max 与 Team 订阅同步获得每月 API 额度（厂商自报）。腾讯新闻
  3. MiniMax 发布 M3.1 Flash——10 月 19 日晚，MiniMax 正式发布新一代 Flash 模型 M3.1 Flash，在复杂 Agent 任务、电脑操作、软件开发及网络安全方面大幅提升，线上推理速度提升近 3 倍、使用成本降低 70%（厂商自报）。南方日报
  4. DeepSeek 更新 V4.1 Flash 并开放搜索 API——10 月 17 日，DeepSeek 更新 V4.1-Flash-1017，强化 Agent 与 Coding 能力、重点提升从零构建完整项目的能力，并同步开放自研 Search / Fetch API（5 元/千次）。今日头条
  5. 谷歌 Gemini 4 Argon 全面开放商用——谷歌旗舰模型 Gemini 4 Argon 全面开放 API 调用，输入 100 万 token 定价 2 美元、输出 10 美元，缓存输入享 95% 折扣，被评价为「经济型旗舰」（厂商自报）。澎湃新闻

板块洞察：本周模型层核心动向是「能力普惠」——旗舰模型价格被大幅拉低、开源权重跑上消费级硬件，模型竞争正从「谁最强」转向「谁最合适」。

安全漏洞

  1. PHP 高危漏洞「PHP2Shell」披露，数小时即遭野外利用——10 月 21 日，PHP 官方修复并披露两个高危 RCE 漏洞（CVE-2026-109618、CVE-2026-109619），影响 WordPress、Drupal、Joomla、Laravel 等主流生态；补丁发布当天亚马逊即检测到 PoC 利用尝试，已确认暴露的受影响服务器超百万台，多国政府机构临时关站应对。经济参考报｜FreeBuf｜山西网信网
  2. 微软 10 月 Patch Tuesday 修复 1413 个 CVE——10 月 13 日，微软发布本年度最大规模安全更新，修复 1413 个漏洞，其中 1 个已遭利用的 Mark-of-the-Web（MOTW）绕过零日漏洞，另有 Exchange 与 Active Directory 高风险修复。IT Business Digest｜Splashtop
  3. Thales SConnect 未认证 RCE 漏洞（CVE-2026-18397）——该漏洞利用加密弱点与内存管理问题组合，可在受害者机器上实现未认证远程代码执行。CVE Record
  4. Oracle SOA Suite 与 Access Manager 曝 CVSS 10.0 漏洞——10 月 21 日安全简报显示，前一日披露的漏洞由 Oracle SOA Suite 与 Oracle Access Manager 的 CVSS 10.0 级漏洞领衔。CVE Brief

板块洞察：安全事件再次证明「协调披露」面临现实挑战——PHP2Shell 补丁发布数小时即遭利用、第三方提前放包加剧风险，修复速度已成为攻防关键变量；AI 也在同时加速漏洞的发现与利用。

开源与开发

  1. DeepSeek 将内部推理框架 DeepInfer 全面开源——10 月 21 日，DeepSeek 宣布将内部推理框架 DeepInfer 全面开源，目标实现大模型普惠。人人都是产品经理
  2. 英伟达开源机器人智能体框架 ASPIRE v1.0——10 月 16 日，英伟达 GEAR 实验室负责人 Jim Fan 宣布 ASPIRE v1.0 以 Apache 2.0 许可证开源，让大模型直接给机器人写控制代码，修好的技能以代码形式沉淀进可复用技能库。AI 工具导航
  3. MemT 1.0 发布：让记忆成为模型内生能力——机器之心报道，MemT 1.0 发布，将长期记忆作为大模型架构的一部分，迈向递归自我改进。36氪
  4. 无问芯穹端侧推理引擎开源，提速 10.7 倍——据 36 氪报道，该端侧推理引擎开源后机器人本体跑大模型不再卡顿（性能为厂商自报）。36氪
  5. 蚂蚁集团开源 Avernet V0.1——蚂蚁集团开源多智能体协作基础设施 Avernet V0.1，夯实多智能体协作底座。Syntho

板块洞察：开源重心正从「模型权重」转向「智能体运行框架与推理引擎」——DeepSeek、英伟达、蚂蚁等接连开源底层基础设施，开源与闭源的能力差、算力差持续收窄。

芯片与算力

  1. 英伟达 Vera Rubin 进入全面生产——10 月 21 日 GTC 柏林，黄仁勋宣布 Vera Rubin 平台进入全面生产阶段，并推出 DSXPOD 参考设计用于建设基于 Vera Rubin 的完整 AI 工厂，同时发布 OpenShell 参考架构。PANews｜新浪财经
  2. 三星将用台积电 3nm 产英伟达 HBM 基础裸片——据韩国《首尔经济日报》报道，三星电子将采用台积电 3 纳米工艺，生产英伟达下一代定制 HBM 的核心部件基础裸片（base die）。证券时报
  3. Bolt Zeus GPU 测试芯片零缺陷，号称路径追踪超 RTX 5090 十倍——GPU 初创公司 Bolt Graphics 宣布完成 Zeus 架构测试芯片调试（台积电 12nm、6mm²、A0 步进零缺陷），商用 GPU 计划 2028 年量产；路径追踪与电磁仿真性能均为厂商自报，待第三方实测验证。网易/快科技
  4. 西门子携手英伟达 cuLitho 加速计算光刻——10 月 14 日，西门子宣布将英伟达 cuLitho 与 Calibre 制造软件集成，全芯片 OPC 最高提速 17 倍，助力下一代 AI 半导体具备可制造性。微纳视界
  5. 进迭时空 V100 亮相 RISC-V 中国峰会——首颗完整符合 RISC-V 服务器规范的芯片亮相，推动 RISC-V 从芯片走向服务器整机。36氪

板块洞察：算力竞争正从单芯片性能转向「工厂级」交付——英伟达用 AI 工厂与参考架构重新定义基础设施，HBM 供应链协作与国产 RISC-V 服务器芯片的进展，则显示算力生态多线并进。
